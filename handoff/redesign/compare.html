Expense Ledger — redesign vs. reference (2026-10-27)

Left: the target reference. Below: the real app, rendered from synthetic test data (no real user data), 390 px wide, in English, Azerbaijani and Russian, plus a 320 px phone. Local build only — nothing is published.

1 · Home Implemented · phone review pending

  • Same order: Safe to Spend → This month (income / spent / third tile) → spending ring → due soon.
  • Differences: greeting without a name (the app does not know it); Safe to Spend keeps its full breakdown (it explains the number); the third tile is the existing surplus % (balance when no income yet).

2 · Transactions Implemented · phone review pending

  • Search, All / Expenses / Income, category and date filters, round category icons, expenses in coral.
  • Differences: grouped by day (as before) rather than by month; "add" is the + in the title bar on every screen instead of a floating button.

3 · Analytics Implemented · phone review pending

  • New Spending trend chart: this month's running total day by day, last month dashed (real data; its end equals "Spent").
  • Differences: a month selector (any month) instead of This month / Last 3 months / Custom; category bars, weekday vs weekend and the 6-month chart are further down the same screen.

4 · Budgets & Goals Implemented · phone review pending

  • Budgets / Goals switch, monthly total card, category rows with progress bars and percent, goal cards with progress.
  • Budgets and goals are now edited here (moved out of Settings). Bar colours show status: green on track, amber near the limit, coral over.

5 · Recurring payments Implemented · phone review pending

  • Under More, with a back arrow. Totals, a "due within 7 days" card, then each schedule with Record payment / Pause.
  • Difference: Active and Paused sections instead of Active / Upcoming / All tabs.

6 · Import / Export Implemented · phone review pending

  • Import and Export cards, a Backups card with the real last-backup date and whether you confirmed you have the file, and a Create backup button.
  • Difference: no "Recent imports" list — the app does not record import history, so it would have to be invented.

7 · Transaction detail Implemented · phone review pending

  • Icon, name, category and date, the amount, and Date / Merchant / Category / Recurring tiles; Edit, Duplicate, Delete.
  • Difference: a sheet over the list (as before); changes are made in the Edit form, not on this screen.

8 · More Implemented · phone review pending

  • Recurring payments, Import / Export, Settings.
  • Differences: no profile, e-mail, dark-mode switch, help or about — none of these exist in the app. The top card says the data is stored only on this device (true).
