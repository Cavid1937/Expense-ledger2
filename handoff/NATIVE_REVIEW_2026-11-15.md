Purpose: a person who speaks Azerbaijani or Russian natively checks the wording below. **None of these strings has had native approval yet.** GPT proposed them; Claude checked them against the code, the glossary and the placeholders. Nothing here is a native-speaker judgement.

Decisions over all 163 GPT proposals (en, az and ru): 150 accepted as written, 12 revised by Claude, 1 rejected.

How to review: for each row, tick OK or write a better text in the last column. Pay most attention to P0 rows (privacy and safety texts) and to every row marked REVISE (Claude's own wording).

Reason column: on ACCEPT rows it is **GPT's** reason, quoted from the workbook; on REVISE and REJECT rows it is **Claude's** reason.

The complete list of every string in all three languages stays in `handoff/az-review-sheet.csv` (rebuilt from the app by `tests/az-audit.mjs`, so it already shows the new wording). This sheet lists only what changed in Run 90.

## Checks Claude made (code evidence, not language judgement)

- **Crash text (crash.body):** every save is written to the phone's storage at once, so entries already saved do survive a crash; only text still being typed can be lost. The new text says exactly that.
- **Help-improve text (learn.ask / learn.never):** compared with what the app really sends (learnPreview in App.jsx): usage counts, shop and place names used at least twice with their category, masked formats of unread bank notifications, masked crash messages, and the app's language, version and platform. The text now names all of these, including the platform.
- **Settings summary (st.sumPrivOff, "App usage sharing is off"):** describes only that switch. The anonymous visit counter (Vercel Web Analytics: no cookies, no ledger data) is not controlled by the switch; it is described in full on the Privacy page (info.privacy.3.b / 3.bA), not hidden in a tip. The old text "Nothing is shared" over-promised and is gone.
- **Google Drive backup:** uses only the app's own hidden Drive folder (drive.appdata scope), as the texts say.
- **Placeholders:** every accepted text keeps the placeholders the app fills in. Two keys leave some out on purpose: `safe.daysLeft` az/ru say "to the end of the month" instead of naming the month (the number is always for the current month, so the meaning is the same); `safe.noteSchedules` az keeps the noun singular after a number (normal Azerbaijani), and ru is built so no plural forms are needed, so neither uses {payments}/{schedules}. A native speaker should still confirm both read naturally.

Standing decisions to keep in mind: an entry in the ledger is *qeyd* / *запись*, but az/ru may still use *əməliyyat* / *операция* in places (owner decision, 12 Nov); no sweeping rename was done.
